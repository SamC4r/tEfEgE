@startuml
!theme vibrant

title Proceso de visualización de video

autonumber

skinparam BackgroundColor FFFFFF
skinparam shadowing false
skinparam RoundCorner 7
skinparam sequence {
    ParticipantPadding 25
    BoxPadding 10
    ArrowThickness 1.2
    LifeLineBorderColor #555555
    LifeLineBackgroundColor #F7F7F7
}

actor "Usuario" as Usuario
participant "Booster Frontend" as Frontend
participant "Booster Backend" as Backend
participant "Sistema de procesamiento\nde videos" as Procesamiento

== Solicitud de reproducción ==

Usuario -> Frontend: Accede a la página de un video
activate Frontend

Frontend -> Backend: Solicita información del video
activate Backend

Backend -> Backend: Consulta metadatos del video
Backend -> Procesamiento: Solicita manifiesto y fragmentos iniciales
activate Procesamiento

Procesamiento --> Backend: Devuelve manifiesto de reproducción\ny fragmentos iniciales
deactivate Procesamiento

Backend --> Frontend: Envía metadatos, manifiesto\ny datos de reproducción
deactivate Backend

Frontend --> Usuario: Muestra reproductor e información del video

== Reproducción del contenido ==

Usuario -> Frontend: Inicia reproducción del video

loop Mientras el video se reproduce
    Frontend -> Backend: Solicita siguiente fragmento de video
    activate Backend

    Backend -> Procesamiento: Solicita fragmento correspondiente
    activate Procesamiento

    Procesamiento --> Backend: Devuelve fragmento de video
    deactivate Procesamiento

    Backend --> Frontend: Entrega fragmento al reproductor
    deactivate Backend

    Frontend --> Usuario: Reproduce fragmento
end

== Registro de visualización ==

alt Usuario con sesión activa
    Frontend -> Backend: Notifica visualización con sesión activa
    activate Backend
    Backend -> Backend: Valida sesión del usuario
    Backend -> Backend: Registra visualización del video
end
@enduml
